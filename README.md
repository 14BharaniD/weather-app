# 🌦️ Weather Dashboard

A responsive weather application built using **HTML, CSS, and JavaScript** with real-time data from the **OpenWeatherMap API**.  
It allows users to search for weather details by city name or automatically fetch data using their current location.  

---

## ✨ Features

- 🔍 **Search by City** – Get weather details for any city worldwide.  
- 📍 **Geolocation Support** – Detects user’s location to fetch local weather.  
- 🌡 **Temperature Unit Toggle** – Switch between Celsius (°C) and Fahrenheit (°F).  
- ⛅ **Dynamic Weather Icons** – Visual icons for conditions (sunny, cloudy, rain, etc.).  
- 🎨 **Responsive UI** – Works seamlessly across devices (mobile, tablet, desktop).  
- ⚡ **Error Handling** – Displays clean error messages (invalid city, network issues).  
- 🌀 **Loading State** – Spinner animation while fetching data.  
- 🌈 **Dynamic Backgrounds** – Background changes based on weather conditions.
